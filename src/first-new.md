# Конструктор

Чтобы связать реальный код с типом, мы используем блоки `impl`:

```rust ,ignore
impl List {
    // TODO, make code happen
}
```

Теперь нам просто нужно разобраться, как на самом деле писать код. В Rust функцию объявляют так:

```rust ,ignore
fn foo(arg1: Type1, arg2: Type2) -> ReturnType {
    // body
}
```

Первое, что нам нужно, — способ *создать* список. Поскольку мы скрываем детали реализации, нужно предоставить для этого функцию. Обычный способ сделать это в Rust — предоставить статический метод, который представляет собой просто обычную функцию внутри блока `impl`:

```rust ,ignore
impl List {
    pub fn new() -> Self {
        List { head: Link::Empty }
    }
}
```

Несколько замечаний по этому поводу:

* `Self` — это псевдоним для «того типа, который я написал вверху рядом с `impl`». Отлично подходит, чтобы не повторяться!
* Экземпляр структуры создаётся почти так же, как она объявляется, — только вместо указания типов полей мы инициализируем их значениями.
* К вариантам enum мы обращаемся через `::` — это оператор пространства имён.
* Последнее выражение в функции неявно возвращается как результат.
  Благодаря этому простые функции выглядят чуть аккуратнее. При этом по‑прежнему можно использовать `return`, чтобы вернуться из функции досрочно, — как в других C‑подобных языках.
